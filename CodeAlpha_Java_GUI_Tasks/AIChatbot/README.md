# JavaBot - Artificial Intelligence Chatbot (Java Swing GUI)

## Features
- Chat-style graphical interface
- Send messages with button or Enter key
- Rule-based keyword/phrase matching
- FAQ responses about Java and OOP
- System date/time responses
- Clear chat and exit/quit handling

## Technical note
This is a rule-based chatbot using simple text normalization and matching. It does not use a trained machine-learning model or an external NLP service.

## Requirements
- JDK 8 or later
- No external libraries required

## Run
```bash
javac -d out src/AIChatbot.java
java -cp out AIChatbot
```
