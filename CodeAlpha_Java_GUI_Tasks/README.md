# CodeAlpha Java GUI Projects

This bundle contains three separate Java Swing GUI projects:
1. StudentGradeTracker
2. StockTradingPlatform
3. AIChatbot

Each project is independent and includes source code, README instructions, and a Windows `run.bat` launcher.

Requirements: JDK 8 or later. No third-party libraries required.

Run any project:
- Windows: open its folder and double-click `run.bat`
- Or open a terminal in that project folder and run the commands in its README.

Note: Each app currently stores its data in memory only. Closing the app resets that data. The stock platform uses sample fixed prices and is not connected to a live exchange.
