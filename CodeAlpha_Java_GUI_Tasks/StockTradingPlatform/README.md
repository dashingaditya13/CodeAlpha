# Stock Trading Platform (Java Swing GUI)

## Features
- Market table with sample stock prices
- Buy and sell shares using a cash balance
- Holdings and market value tracking
- Average purchase cost and unrealized profit/loss
- Transaction history and input validation

## Important
This is an educational paper-trading simulation. Prices are sample fixed values, not live market data. Data is held in memory and resets when the program closes. No real money or brokerage is involved.

## Requirements
- JDK 8 or later
- No external libraries required

## Run
```bash
javac -d out src/StockTradingPlatform.java
java -cp out StockTradingPlatform
```
